# SWE-QA 20题修复后复验

本轮补跑代码增强BM25和Agentic各20题，共40个新答案、116次本地生成调用，付费API调用为0。混合重排复用上一轮修复后的20题：逐题核对配置、检索策略、源码和生成消息完全一致，未重复生成。闭卷与普通BM25沿用已验证输入不变的封存结果。原始失败均保留。

沿用[原选题及仓库提交](../sweqa-20-review-2026-11-03/selection.json)：Flask、Requests、Pytest、Streamlink各5题。这20题已经揭盲，本轮属于开发回归，不能作为独立测试集。方法沿用[官方五维评分标准](https://github.com/peng-weihan/SWE-QA-Bench/blob/c13deac7a0d99b0ca2e593e004c4739475785b08/Benchmark%20construction/score/llm-as-a-judge.py)，由当前Codex会话非盲模型辅助评审；每维1–20分，总分5–100，**不是正确率，也不是论文GPT-5评审的复现**。三个正文逐字相同的答案沿用原分数，评分记录标明来源。

固定Qwen3.5-9B Q4_K_M、16K上下文、2048输出上限、temperature=0、seed=42；初始最多6个源码单元、8000字节。神经检索仍使用既有Qwen3-Embedding/Reranker-0.6B与FAISS，Agent仍使用既有SDK Runner，每题最多6次生成、6次仓库工具调用。Agent还具有不同提示词、静态导航与多轮交互，因此这不是纯工具消融。

代码增强9题上升、9题持平、2题下降；Agentic为11/3/6。按仓库聚类重采样的95%区间分别为[-1.85, 9.90]与[-3.60, 7.30]，均跨0。当前Agentic比混合重排高5.90分，区间[-1.20, 10.90]同样跨0。样本只有4个仓库，且是非盲开发题评分，无法据此宣称稳定提升。普通BM25仍高于代码增强BM25，这批结果不支持默认增加增强步骤。

本轮确认并修复一处工程bug：`benchmark.index_for`的索引缓存键漏掉排除文件范围和预期commit，可能复用错误范围的索引、跳过新任务的commit检查。现有键加入commit及规范化排除路径，新增回归用例在修改前失败、修改后通过。此处仅改1行运行代码，无新增运行模块。这20题的排除列表均为空、每个快照提交一致，因此该bug没有影响这批分数，不能把分数变化归功于它。

排序修复改变了两组各17题的初始证据，故补跑有必要。完整离线回归373项通过、1项默认排除，Ruff通过；40个结果与116次请求账本一致，实际请求中的972段源码全部与固定提交一致。流程成功和源码传输正确均不代表答案正确。本轮服务已停止。

失败与收益集中在以下案例，详见[失败分析](failure-analysis.json)：

- `flask-017`：单次检索没有TagBytes定义，答案虚构`__binary__`；Agent补读后正确给出`" b"`标签及Base64/ASCII转换链。
- `pytest-015`：完整函数已进入实际请求，Agent仍把`prefix + '*'`写成追加`'/'`，并错解排序后去前缀，属于生成理解错误。
- `streamlink-012`：Agent反复限定`stream/hls`或`stream`搜索，未到插件侧找到NicoLive实现，属于搜索范围决策失败。
- `streamlink-037`：Agent从原97分回退到31分，未找到`Arguments.requires`；保留回退答案与全部搜索轨迹，没有按结果重试或替换最好答案。
- `flask-009`：Agent拿到实现后仍混淆Flask实例与ScriptInfo，额外读取没有保证更好的依赖链解释。

Agent累计78次工具尝试，其中11次`already_read`、6次`duplicate_action`；它们消耗预算，不能当成有效证据增量。无新增模块、特殊题目别名或提示词变体。后续优先依据这些失败判断检索与生成的责任，不继续扩大本轮实验。

`pytest-023`的官方参考存在已预先记录的继承屏蔽语义错误。主结果保留全部20题，另报去掉该题的19题敏感性结果；其余参考与原分母不改。没有官方gold源码范围，故不报告gold Recall@K。耗时受缓存和GPU模型切换影响，不能解释为冷启动性能对比。
