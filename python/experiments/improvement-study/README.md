## 报告口径

首次 8 道源码题、2 道私有题、预选 2 题的重复分别展示。各条件记录事实、核心支持、完整解决、完整性、私有拒答方向及 `insufficient_evidence` 字段；三条件逐题配对，公开增/失/双过/双未过的 task_id。全部原始流程失败均保留，不能删除失败或用重跑替代。结构成功和引用范围合法不等于语义正确。

工具新增取证要求观察中实际返回此前未见的非空原文行，不能只数工具名、命中元数据或范围。脚本记录新增行数、最终输入保留数、`already_read` 和没有新增原文的调用，并列出与语义解决的关联。新取证也可能无关、未被正确使用或在最终整理时丢失，因此该关联不等于因果解释。原文已见与当前最终输入可见分开；空 `final_context` 不用“曾读内容”补齐。

初始/最终参考完整度是预设行段覆盖的代理，包含严格范围与实际非空行覆盖。参考可能同时列实现、测试或不同证明，替代有效来源也可能不在其中，不能用未完整覆盖直接宣布答案错误。

成本使用原始请求和已观测 token，缺失用量/时间仍标缺失。整段耗时统一使用 `evaluation_elapsed_seconds`，生成器请求耗时另记，缓存命中不会冒充本次新请求。硬件、模型、量化、上下文、采样、CPU 检索及缓存冷/热状态来自明确声明；未记录项不推测。运行未隔离后台任务时不能把微小耗时差当成稳定速度收益。

Wilson 95% 区间只描述当前条件计数；配对 Clopper–Pearson 区间描述“不一致对中候选获胜概率”，不是准确率提升的效应量区间。小样本、作者选题、同库多题和两题同 seed 重复不支持总体精度或统计泛化结论。重复不扩大独立问题分母，不择优保留。

P3 题库覆盖两个新加入仓库的若干真实 API 使用问题；公开代码仍可能出现在模型预训练中，封存最终测试仓库保持关闭。两个固定追问历史是预写条件切换，不冒充真实多轮用户会话。评审与子 Agent 复核按其实际模型辅助来源记录，`human_participants=0`；模拟仅说明操作可用性与证据缺陷，不能改称真人节时、满意度或业务 ROI。
