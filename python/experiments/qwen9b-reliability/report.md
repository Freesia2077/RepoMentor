## 配置与边界

单次读取由硬编码约 3KB/100 行改为可记录的 8000 字节/200 行；工具观察 12000 字节、累计源码 36000 字节。研究输出上限 1536、最终输出 2048，输入、工具格式、模板余量与输出合计不超过 16384。每题最多 6 次请求、6 次工具、360 秒，专家关闭。

续读参数根据实际返回区间重新计算，避免跳过未读区间或重复可见内容。SDK 调用前提供阅读进度，工具仍由模型选择。最终整理收到最多 4000 字节的已完成研究要点；要点不是证据，原文优先，截断草稿和 provider reasoning 不传入最终阶段。

这些是流程与预算的组合变化，不是各组件的独立因果消融。依据已安装 SDK 与 [OpenAI Docs：运行循环](https://developers.openai.com/api/docs/guides/agents/running-agents)、[结果与状态](https://developers.openai.com/api/docs/guides/agents/results)实现，未恢复自研循环。
