# 非后训练阶段的冻结验证协议

2026-10-23。用户要求执行[建议文档](project-improvement-proposal-2026-10-23.md)的全部非后训练阶段，并明确授权本轮最多 **96 次本地 Qwen 请求**。起点累计 1150 次，本轮累计上限 1246；不是把旧剩余 36 次另加在 96 次上。只使用已部署 Qwen3.5-9B Q4_K_M、Ollama 0.34.3、16K、thinking off、temperature=0、top_p=1、seed=42；不付费、不自动重试、不启动训练。

## P2：一个输出约束干预

假设：部分源码解释在最终整理时被压缩掉，将最终答案约束为“分项结论 + 对应解释”，能保留必要机制，而不降低事实正确性。它不负责修复检索缺口或模型对显式参数的误读。

固定 6 道已知开发题：mitt 大小写与测试、TinyDB 缓存刷新、LRU 访问与成员检查、Nanoid 显式小数长度、Chalk null 转换、dotenv 私有运行状态。每题两次单调用 SDK finalizer 重放，共最多 12 次。原研究要点、实际最终源码、历史、系统指令、采样、输出 token 上限及 schema 之外的请求字段逐字一致。控制沿用字符串答案 schema；候选仅将 answer 改为结论/解释列表，呈现时确定性拼接回现有 RepositoryAnswer。原始结构输出和失败保留，不复制研究稿作为答案。

评分按原问题必需命题，接受等价解释与替代来源。先复核事实、引用支持、完整性、拒答标志，再看完整解决的配对得失。候选进入新确认的条件：解释完整性有配对净增，原正确事实/核心不丢失，私有问题不新增错误，新增引文/格式失败不增加。否则保留简单方案并照常确认当前基线。一次未通过就停止该候选，不再在同题上追调。

这是已知题上的模型辅助开发诊断，不作为新泛化成绩。重放只衡量 finalizer，不冒称完整 Agent 的新结果。完整代码、依赖、请求和数据身份在生成前保留，外部要点不含供应商私有 reasoning。

## P3：冻结的新仓库确认与重复

题目已在任何本轮生成前由独立子 agent 固定，见 [确认设计](../experiments/improvement-confirmation-design/dataset.json)和 [问题哈希](../experiments/improvement-confirmation-design/manifest.json)。两仓库为 pallets-eco/blinker、jd/tenacity，10 题包含 8 源码可答、2 私有运行信息题。固定追问历史是预写条件切换，不冒充真实连续会话；原 P0 最终测试仓库继续封存。

每题三个条件：固定 BM25 代码增强 RAG，SDK 同阶段策略关闭工具，SDK 同阶段策略开启工具。来源选择、当前问题、历史、模型和最终公开输出合约匹配；工具开/关持有相同 3 次决策、6 工具上限，权限关闭时仍运行研究并按同一规则整理。研究能直接提交合法答案时两条件都允许提前结束，实际请求数据实披露。固定 RAG 最多 1 次，两 SDK 各最多 3 次，10 题最多 70 次。它隔离工具权限，并不把固定 RAG 与多次推理的差异全部归因于 Agent。

预选 blinker-02 和 tenacity-01 两题，三个条件各独立重复一次，最多 14 次；独立缓存/请求，不挑最好结果。相同 seed 的重复仅观察本地运行稳定性，不代表充分的随机性估计。总预算 12 + 70 + 14 = 96。首次和重复分开统计，重复不扩大独立题数。

新题/评分点对待测模型隔离；只给问题、历史、检索和工具实际交付的原文。设计涉及两个新仓库，仍不能证明没有预训练污染。许可、快照、去重覆盖和未检查范围随设计封存。

## 评审、模拟与交付

先隐藏条件标签并随机排序，按源码逐项评审；独立子 agent 复核与实施者自审分开保存，记录分歧，不覆盖原判断。评审绑定完整结果行及可见来源，不能从合法行号自动推出语义正确。`human_participants=0`；agent 模拟仅报告操作可用性与证据缺陷，不估计人类节时或业务 ROI。

每个生成批次维持 dataset、results、summary、completed-files 四份主文件；评审包、报告与代码快照单独归档。报告分别呈现事实/核心/完整、拒答与标志、配对增失、初始/最终来源覆盖、有效新增取证、重复无进展、错误停止、全部失败、请求和 token/耗时。缺失用量不伪造为零；端到端耗时使用新统一测量字段，声明 CPU 索引缓存与 GPU 热启动情况。

若新确认不支持改进，保持固定 BM25 的日常入口；SDK 保留为显式研究能力，不用调参后的确认集反复证明自身。最后更新当前实现、唯一计划、交接说明、系统卡和 5–8 分钟可回放面试材料。MiniMind/Qwen 的 SFT、DPO、GRPO、教师数据生产与训练部署均排除。
