# 数据与评测协议

本页维护来源、划分和评价口径。实际成绩只引用[50题报告](../experiments/sweqa-50-2026-11-03/README.md)，其他任务按[实验索引](experiment-index.md)各自解释。

## 来源与隔离

- 目标仓库读取固定commit/tree/blob，记录相对路径、行号、内容哈希和许可；不读取未提交checkout、不跟随symlink/submodule，不安装或执行目标代码。
- 原[P0语料](../experiments/p0/corpus.json)为20仓库、训练12/验证4/最终测试4。补充开发仓库不改变原划分，原四个最终测试库继续封存。
- 原跨集合检查采用20-token shingles、至少80 tokens文件和containment≥0.8阈值，1,159份文件未发现阈值以上重合。它不覆盖短片段、语义改写和预训练污染。
- 题干、评分命题与参考源码分开，普通生成仅接收问题、真实检索和工具返回；gold来源仅用于显式oracle诊断，评审补读不属于生成输入。

## 当前公开评测

SWE-QA数据revision、作者仓库版本、固定SHA和选题保存在[selection.json](../experiments/sweqa-50-2026-11-03/selection.json)。原数据720题/15库，本轮为四库50题×5组，不能称为全量复现。

旧20题已用于开发，新增30题生成前冻结，排除本地题库和旧样本的规范化同文题；只有精确题干去重，没有语义去重或预训练污染证明。旧100份答案/评分原样复用，新150份不挑最好尝试，两批分开报告。

闭卷允许先验知识且不含源码；普通BM25、代码增强、混合重排为单次生成；Agent使用同题混合组的相同初始原文继续补查。提示、导航与多轮预算也有差异，因此是完整流程比较，不是纯工具因果消融。

五维量表各1–20分，总分5–100。评审由模型辅助，新增隐藏条件标签但编排者仍能接触原记录；非独立盲评、非人工准确率。参考存在问题时保留主分母与原件，另报敏感性分析，不换题或覆盖失败。

## 问题身份与轨迹

稳定问题身份由仓库、SHA、题干、前序用户问题/声明历史及分区组成。改写、版本或上下文不同不自动合并，别名和重复尝试不扩大题数。使用`questions`查询[统一题库](../experiments/question-bank.json)，不导入最终封存测试。

新确认在生成前冻结问题、必要事实、来源、条件和采用门槛；揭盲后转为开发数据。公开50题、失败修复题及旧评测不进入后训练。未来第二项目沿用相同来源与工具协议，另行审核训练/评测重合。

轨迹保留完整请求、原始输出、结束原因、工具参数/返回、上下文取舍、实际可见源码及哈希。存档原文、研究笔记、旧助手答案和导航位置不等于当前模型见过的原文；合法行号不证明自然语言结论正确。

## 历史业务评分与成本

旧业务任务的`factually_correct`、`core_supported`、`fully_resolved`分别衡量整答事实、可见来源支持和题意完整覆盖；不能与公开五维均分互换。私有状态问题同时检查正文拒答、额外断言和`insufficient_evidence`。重复、私有题、开发/确认与不同版本分开统计。

历史交叉试用由两个模型代理完成，真人参与为0。最终纠错后的业务决定不能当作原Qwen自动回答成绩；额外查读与初始预取一并计入总源码成本，不推算真人省时或线上收益。

请求账本计入已发送及发送状态不确定的请求，不自动重发。未知usage/time保留未知，不伪造为0；模型请求数不是token/金额倍数，跨实现elapsed和跨tokenizer的token数也不直接等价。冷/热索引、GPU换入换出与重复尝试须按实际说明。

## 原件保护

已封存的输出、失败、评分和哈希清单不覆盖；纠错另留可追溯说明。被拒候选的结果照常保留，不删失败或事后改门槛。模型辅助评审始终保留`human_approved=false`性质。

模型、量化、提示、工具、采样、上下文、实现与索引身份进入缓存；身份变化后新建会话。模型设置、凭据、权重、仓库缓存和数据库不提交。历史完整性用`verify_archives.py`离线核验；无独立证据的Markdown展示可从原始记录重新导出，不作为新成绩。
