# RepoMentor：简历项目段落

## 标准版

**RepoMentor｜面向开源仓库学习的 Agentic RAG 助手**　个人项目

**技术栈：** Python、Tree-sitter、BM25、FAISS、Qwen3 Embedding/Reranker、OpenAI Agents SDK。

**项目简介：** 面向开发者学习和接手开源仓库，提供仓库学习报告与交互式源码问答，覆盖架构导览、源码阅读路线、函数实现及相关测试，帮助理解模块关系与实现逻辑。

- **代码检索：** 基于固定Git快照与Tree-sitter结构切分，构建BM25/FAISS双路召回、RRF融合及Qwen3重排流程，结合符号、路径和有限静态依赖定位源码，保留声明范围与原始行号，支持精确标识符和语义检索。
- **按需取证：** 设计“初始检索—工具补查—观察反馈—引用作答”的Agentic RAG流程，基于OpenAI Agents SDK组织六类只读函数工具；由模型根据当前证据选择补查目标、构造查询与读取范围，结合工具返回继续推理或提交带引用答案。
- **Agent harness：** 构建仓库学习任务的运行约束层，管理上下文裁剪、工具去重、调用预算与检查点恢复；区分已读取和当前可见源码，按实际输入校验引用，阻止引用同批读取但尚未进入模型输入的源码。
- **SWE-QA评测：** 固定Qwen3.5-9B与仓库版本，在四库50题上完成五组同题对照（250份答案）；依据参考答案与源码，按官方五维量表进行模型辅助评分，闭卷、BM25、代码增强、混合重排、Agentic RAG均分依次为47.64、64.46、63.36、70.52、77.96；Agent平均生成请求4.5次/题，单次生成组为1次。

## 面试时补充的口径

- 50题由旧20题和新增30题组成，旧题已用于开发；五维模型辅助均分不是准确率，也不是独立人工盲评。完整方法、成本、逐题退步及参考问题见[评测报告](../experiments/sweqa-50-2026-11-03/README.md)。
- 闭卷没有源码或参考答案，允许使用先验知识；五维为正确性、完整性、相关性、清晰度、推理质量，各1–20分，总分5–100。量化生成器实际为Qwen3.5-9B Q4_K_M；代码增强负结果仍保留。
- Harness是任务级工具、上下文、状态与运行约束，Agent循环复用SDK；引用范围合法不保证语义正确，当前没有各harness机制的独立质量消融。
- 学习报告由`report`的explorer、mentor、contributor固定串行生成，前两者提供入口/模块和架构/阅读路径；`ask/chat`提供函数与测试解释。公开分数仅对应源码问答，未验证报告整体质量、真人学习提效或线上收益。时间与个人职责按实际填写。

开场与案例见[面试稿](interview-playbook.md)，实现、公式、harness证据和岗位资料见[技术问答](rag-interview-assessment.md)，原始记录见[实验索引](experiment-index.md)。
