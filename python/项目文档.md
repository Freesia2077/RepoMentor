# RepoMentor Python：当前实现

使用命令见[README](README.md)，模型字段见[配置示例](config/model-settings.example.json)，评测方法与原件见[SWE-QA 50题报告](experiments/sweqa-50-2026-11-03/README.md)。RAG源码在[src/repomentor](src/repomentor/)，后训练源码在[src/sftgrpo](src/sftgrpo/)。

## 业务与交付

面向开发者学习、理解和使用开源仓库，从架构入口和阅读路线开始，逐步追问函数、模块关系、依赖与测试，并提供接入和贡献准备建议。

| 使用阶段 | 已有交付 | 入口 |
| --- | --- | --- |
| 学习陌生仓库 | 概览、入口、模块说明、源码阅读路线和信息缺口 | `report`的explorer / mentor阶段 |
| 理解实现 | 函数行为、有限静态关系、关联测试与连续追问 | `ask` / `chat`及只读仓库工具 |
| 使用与贡献准备 | 参数行为解释、阅读/测试路线与有据建议 | 共享取证及report的contributor阶段 |

`report`默认运行[SdkReport](src/repomentor/sdk_report.py)：从README、项目清单、入口与测试候选选取原文，各阶段经SDK补查后输出结构化结果。explorer提供`entryPoints/moduleMap`，mentor提供`architectureOverview/readingPath`，contributor提供入门与贡献建议；前序摘要只作导航，可复用的原始来源重新核验。`ask/chat`则按具体问题定位函数、读取实现和测试断言，交付解释与引用。

学习报告采用固定串行阶段，普通问答为单Agent。目标仓库只读固定Git快照，不安装或执行其代码，不自动修改或提交PR；贡献建议不冒称真实issue。学习效率、接手耗时与贡献成功率尚未独立量化。

## 实现主线

固定Git快照 → 结构切分和索引 → 共享检索与原文打包 → 单次RAG / SDK按需取证 → 答案与可见引用校验 → 保存会话和运行记录。

- **检索：** Tree-sitter结构切分，支持BM25、向量、RRF混合与Qwen重排。符号、路径和有限静态调用/导入关系辅助定位，不能替代运行时分派或程序验证。
- **存储：** 源码块JSON与内存BM25；归一化向量采用NumPy缓存、FAISS IndexFlatIP检索。SQLite保存运行与请求账本，不是向量数据库。
- **按需取证：** 六个只读工具提供代码/文档搜索、原文读取、测试、符号及依赖导航。OpenAI Agents SDK Runner执行循环，项目不维护自研Agent循环。
- **Harness：** 管理工具契约、去重、预算、上下文取舍、当前可见原文、提交范围及检查点。`submit_answer`可合法结束，越界则返回错误；需要时使用类型化finalizer整理。
- **输出与追问：** 保存原始答案、来源、工具和模型请求；会话固定模型、快照、配置及实现身份，支持显式恢复和完成请求回放。

## 默认与对照

| 选择 | 实际行为 |
| --- | --- |
| 产品默认 | 代码增强BM25/CPU提供初始原文，SDK Agent按需补查 |
| `--engine rag` | 取证一次、生成一次；复用同一取证组件 |
| `--retriever hybrid-rerank` | 显式启用BM25/向量、RRF及重排；不改变engine职责 |
| `--no-code-aware` | 关闭符号和代码关系增强，保留所选检索器 |

公开50题评测中的Agent显式选用混合重排，与对应混合RAG使用相同初始原文。产品默认参数见[配置示例](config/model-settings.example.json)，各组冻结的模型窗口、取证与调用预算见[评测协议](experiments/sweqa-50-2026-11-03/README.md)。

## 效果与适用范围

[SWE-QA 50题报告](experiments/sweqa-50-2026-11-03/README.md)保存五组250份答案、旧20/新30分批结果、成本、参考问题和源码核验。该样本中检索总体优于闭卷，Agent均分最高且成本更高；代码增强未超过普通BM25，仍有逐题退步。模型辅助量表分数不是人工准确率，不代表完整720题或新仓库泛化。

早期业务开发、工具配对与修复实验保存在[experiments](experiments/)的各批次记录中，各自保留原分母与结果。真人学习效率和线上收益尚未独立评测。

引用合法只说明来源身份与范围可见，不能证明自然语言解释正确；研究笔记、导航位置和历史摘要不替代当前原文。提示中把源码指令视为数据，尚无完整提示注入攻防结论。发送中途失败不保证远端请求恰好执行一次。
