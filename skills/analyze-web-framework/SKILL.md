# Web 框架分析策略

## 关注重点

- 路由定义方式与请求生命周期
- 中间件/插件机制的设计模式
- 配置加载与启动流程
- 模板引擎和响应渲染机制
- 扩展点：如何添加自定义中间件/插件

## 推荐探索路径

1. 找到应用入口：查看 package.json 的 main/bin 字段，或启动脚本
2. 理解路由系统：搜索 router、routes 关键词，理解 URL → handler 的映射
3. 跟踪请求生命周期：从监听端口 → 路由匹配 → 中间件链 → 响应
4. 学习配置机制：查看 config/ 目录或配置文件加载方式
5. 了解扩展机制：如何编写和注册插件/中间件

## 常见架构模式

- 洋葱模型（中间件层层包裹）
- 工厂模式创建应用实例
- 观察者模式用于生命周期钩子
